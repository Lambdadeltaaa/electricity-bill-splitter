# Electrical Bill Splitter
A simple web app I made to help split a household electricity bill based on individual room sub-meters reading and shared common areas.

Access the web app here: https://split.lambdas.me/

> 📌 **Disclaimer:**
> This tool is built mainly for personal use in Malaysia, do double-check calculations for important splits if you use it yourself.
> In Malaysia, the proportional formula is no longer accurate when total household usage exceeds 1000kWh. Don't rely on it if so.



## Features:
- Computes individual room usage from previous and current kWh readings.
- Deducts total room usage from the main bill and splits the remaining common area kWh among included rooms by number of people.
- Determine each room's cost based on percentage of the total electricity used.
